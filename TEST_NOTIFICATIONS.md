# 🧪 Тестирование уведомлений

## ✅ Что было исправлено:

1. **Дублирование уведомлений при открытии из фона**
   - Уведомления не показываются повторно в течение 5 секунд после открытия приложения из фона

2. **Уведомления когда чат открыт**
   - Уведомления НЕ показываются, если чат с пользователем уже открыт
   - Работает для Web и Mobile (iOS/Android)

## 📋 Сценарии для тестирования:

### Тест 1: Уведомление когда чат закрыт ✅
1. Откройте приложение на iOS
2. **НЕ открывайте** чат с пользователем
3. Отправьте сообщение с веб-версии на iOS
4. **Ожидаемый результат:** Уведомление должно появиться

### Тест 2: НЕТ уведомления когда чат открыт ✅
1. Откройте приложение на iOS
2. **Откройте** чат с пользователем
3. Отправьте сообщение с веб-версии на iOS
4. **Ожидаемый результат:** Уведомление НЕ должно появиться (пользователь видит сообщение)

### Тест 3: НЕТ дублирования при открытии из фона ✅
1. Отправьте сообщение с веб-версии на iOS, когда приложение в фоне
2. Должно появиться push-уведомление
3. Откройте приложение из уведомления
4. **Ожидаемый результат:** Уведомление НЕ должно появиться повторно

### Тест 4: Уведомление после открытия чата и закрытия ✅
1. Откройте чат с пользователем
2. Закройте чат (вернитесь в список чатов)
3. Отправьте сообщение с веб-версии на iOS
4. **Ожидаемый результат:** Уведомление должно появиться

### Тест 5: Уведомление в другом чате когда один открыт ✅
1. Откройте чат с пользователем A
2. Отправьте сообщение от пользователя B с веб-версии на iOS
3. **Ожидаемый результат:** Уведомление должно появиться (это другой чат)

## 🔍 Что проверять в логах:

При получении сообщения должны появиться логи:
```
[ChatProvider] 📨 Message parsed:
[ChatProvider]   - ChatID: chat_xxx
[ChatProvider]   - isCurrentChat: true/false
[ChatProvider] ℹ️ Чат открыт - уведомление не показано (пользователь видит сообщение)
```
или
```
[ChatProvider] 📱 Mobile: Чат не открыт - показываем локальное уведомление
[ChatProvider] ✅ Локальное уведомление показано
```

## ⚠️ Известные ограничения:

- Подавление уведомлений при открытии из фона работает только в течение 5 секунд
- Если сообщение придет через WebSocket позже 5 секунд после открытия, уведомление может появиться
