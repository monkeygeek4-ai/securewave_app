## 🍎 ШАГ 2: Подготовка Apple Developer аккаунта

### 2.1. Проверка членства в Apple Developer Program

1. Перейдите на [developer.apple.com](https://developer.apple.com)
2. Войдите в свой аккаунт
3. Убедитесь, что у вас активное членство ($99/год)
4. Проверьте Team ID: `Q5CPN332XB`

### 2.2. Настройка App ID в Apple Developer Portal

1. Откройте [App IDs](https://developer.apple.com/account/resources/identifiers/list/bundleId)
2. Найдите или создайте App ID: `com.securewavenew.app`
3. Убедитесь, что включены необходимые Capabilities:
   - ✅ Push Notifications
   - ✅ Background Modes (Remote notifications, VoIP, Audio)
   - ✅ Associated Domains (если используется)

### 2.3. Создание App Store Connect записи

1. Перейдите на [App Store Connect](https://appstoreconnect.apple.com)
2. Нажмите **"Мои приложения"** → **"+"** → **"Новое приложение"**
3. Заполните информацию:
   - **Платформы:** iOS
   - **Название:** SecureWave (или ваше название)
   - **Основной язык:** Русский (или нужный)
   - **Bundle ID:** `com.securewavenew.app` (выберите из списка)
   - **SKU:** `securewave-app-001` (уникальный идентификатор)
   - **Пользовательский доступ:** Полный доступ (или ограниченный)

## 🔧 ШАГ 3: Подготовка проекта к релизу

### 3.1. Обновление версии приложения

В файле `pubspec.yaml`:
```yaml
version: 1.1.0+2
```
- Первое число (1.1.0) - версия для пользователей
- Второе число (+2) - build number для App Store

**Рекомендация:** Для первого релиза используйте `1.0.0+1`

### 3.2. Проверка Info.plist

Убедитесь, что все описания разрешений на русском языке (если приложение на русском):

```xml
<key>NSCameraUsageDescription</key>
<string>SecureWave нужен доступ к камере для фото и видеозвонков</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>SecureWave нужен доступ к фотогалерее для отправки фотографий</string>
<key>NSMicrophoneUsageDescription</key>
<string>SecureWave нужен доступ к микрофону для голосовых и видеозвонков</string>
```

### 3.3. Обновление ExportOptions.plist для App Store

Файл `ios/ExportOptions.plist` должен содержать настройки для App Store:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>method</key>
	<string>app-store</string>
	<key>signingStyle</key>
	<string>automatic</string>
	<key>teamID</key>
	<string>Q5CPN332XB</string>
	<key>uploadBitcode</key>
	<false/>
	<key>uploadSymbols</key>
	<true/>
	<key>compileBitcode</key>
	<false/>
	<key>destination</key>
	<string>upload</string>
</dict>
</plist>
```

### 3.4. Проверка иконки приложения

1. Убедитесь, что есть иконка в `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
2. Размеры иконок должны быть:
   - 1024x1024 (для App Store)
   - 60x60, 120x120, 180x180 (для устройства)

### 3.5. Проверка Launch Screen

Убедитесь, что Launch Screen настроен в `ios/Runner/Base.lproj/LaunchScreen.storyboard`

## 🏗️ ШАГ 4: Сборка релизной версии

### 4.1. Очистка проекта

```bash
cd /Users/vladimir/development/securewave_app
flutter clean
flutter pub get
cd ios
pod deintegrate
pod install
cd ..
```

### 4.2. Сборка через Xcode (рекомендуемый способ)

1. Откройте проект в Xcode:
   ```bash
   open ios/Runner.xcworkspace
   ```

2. В Xcode:
   - Выберите **Product** → **Scheme** → **Runner**
   - Выберите **Any iOS Device** (не симулятор)
   - Выберите **Product** → **Archive**

3. Дождитесь завершения архивации

4. В окне **Organizer**:
   - Выберите созданный архив
   - Нажмите **Distribute App**
   - Выберите **App Store Connect**
   - Выберите **Upload**
   - Следуйте инструкциям мастера

### 4.3. Сборка через командную строку

```bash
# Сборка IPA файла
flutter build ipa --release

# Или с указанием ExportOptions
flutter build ipa --release --export-options-plist=ios/ExportOptions.plist
```

Готовый IPA файл будет в: `build/ios/ipa/securewave_app.ipa`

### 4.4. Загрузка через Transporter (альтернативный способ)

1. Установите [Transporter](https://apps.apple.com/app/transporter/id1450874784) из Mac App Store
2. Откройте Transporter
3. Перетащите IPA файл в окно Transporter
4. Нажмите **Deliver**
5. Войдите в Apple ID с доступом к App Store Connect

## 📝 ШАГ 5: Настройка в App Store Connect

### 5.1. Основная информация

1. В App Store Connect откройте ваше приложение
2. Перейдите в раздел **"App Information"**
3. Заполните:
   - **Категория:** Социальные сети / Коммуникации
   - **Подкатегория:** (опционально)
   - **Контент для детей:** Нет (если не детское приложение)

### 5.2. Подготовка скриншотов

Требуются скриншоты для разных размеров устройств:

**iPhone 6.7" (iPhone 14 Pro Max, 15 Pro Max):**
- 1290 x 2796 пикселей (портрет)
- Минимум 1, максимум 10 скриншотов

**iPhone 6.5" (iPhone 11 Pro Max, XS Max):**
- 1242 x 2688 пикселей (портрет)
- Минимум 1, максимум 10 скриншотов

**iPhone 5.5" (iPhone 8 Plus):**
- 1242 x 2208 пикселей (портрет)
- Минимум 1, максимум 10 скриншотов

**iPad Pro 12.9":**
- 2048 x 2732 пикселей (портрет)
- Минимум 1, максимум 10 скриншотов

**Как сделать скриншоты:**
1. Запустите приложение на симуляторе нужного размера
2. Сделайте скриншоты (Cmd + S)
3. Или используйте реальное устройство

## 🚀 ШАГ 6: Отправка на модерацию

### 6.1. Финальная проверка перед отправкой

- [ ] Версия приложения соответствует версии в App Store Connect
- [ ] Все скриншоты загружены
- [ ] Описание заполнено на всех языках (если мультиязычное)
- [ ] Политика конфиденциальности доступна по ссылке
- [ ] Иконка приложения загружена
- [ ] Рейтинг контента заполнен
- [ ] Тестовые аккаунты созданы (если требуется)
- [ ] Примечания для рецензента заполнены

### 6.2. Примечания для рецензента

В разделе **"App Review Information"** заполните:

**Примечания:**
```
Приложение SecureWave - это мессенджер с шифрованием.

Для тестирования:
- Email: test@example.com
- Пароль: TestPassword123

Особенности:
- Требуется регистрация для использования
- Push-уведомления настроены через Firebase
- VoIP звонки работают через WebRTC
```

**Контактная информация:**
- Имя: Ваше имя
- Телефон: +7 (XXX) XXX-XX-XX
- Email: ваш-email@example.com

### 6.3. Отправка на модерацию

1. В разделе **"App Store"** → **"Версия 1.0"**
2. Проверьте, что все разделы заполнены (зеленые галочки)
3. Нажмите **"Отправить на рассмотрение"**
4. Подтвердите отправку

### 6.4. Ожидание модерации

- **Обычное время:** 24-48 часов
- **Максимальное время:** до 7 дней
- Статус можно отслеживать в App Store Connect

**Возможные статусы:**
- ⏳ **Waiting for Review** - ожидает рассмотрения
- 🔄 **In Review** - на рассмотрении
- ✅ **Ready for Sale** - одобрено и готово к продаже
- ❌ **Rejected** - отклонено (с указанием причины)

## ⚠️ Частые проблемы и решения

### Проблема: Ошибка подписи кода

**Решение:**
1. Проверьте сертификаты в Keychain Access
2. Обновите provisioning profiles в Xcode
3. Используйте автоматическую подпись в Xcode

### Проблема: Ошибка при загрузке IPA

**Решение:**
1. Проверьте размер файла (максимум 4GB)
2. Убедитесь, что используется правильный ExportOptions.plist
3. Проверьте интернет-соединение

### Проблема: Отклонение модерации

**Решение:**
1. Внимательно прочитайте причину отклонения
2. Исправьте указанные проблемы
3. Добавьте примечания для рецензента
4. Отправьте повторно

### Проблема: Ошибки сборки Flutter

**Решение:**
```bash
flutter clean
flutter pub get
cd ios
pod deintegrate
pod install
cd ..
flutter build ipa --release
```
