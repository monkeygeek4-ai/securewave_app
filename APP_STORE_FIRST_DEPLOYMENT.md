## ✅ ШАГ 1: Подготовка Apple Developer аккаунта

### 1.1. Проверка членства

1. Откройте [developer.apple.com](https://developer.apple.com)
2. Войдите в аккаунт
3. Убедитесь, что у вас активное членство **Apple Developer Program** ($99/год)
4. Проверьте **Team ID**: `Q5CPN332XB`

### 1.2. Настройка App ID

1. Перейдите в [App IDs](https://developer.apple.com/account/resources/identifiers/list/bundleId)
2. Найдите или создайте App ID: **`com.securewavenew.app`**
3. Убедитесь, что включены Capabilities:
   - ✅ **Push Notifications**
   - ✅ **Background Modes** (Remote notifications, VoIP, Audio)
   - ✅ **Associated Domains** (если используется)

### 1.3. Проверка сертификатов

1. В разделе [Certificates](https://developer.apple.com/account/resources/certificates/list)
2. Убедитесь, что есть:
   - ✅ **Apple Distribution** сертификат (для App Store)
   - ✅ Сертификат действителен (не истек)

**Если сертификатов нет:**
- Xcode создаст их автоматически при архивации
- Или создайте вручную в Developer Portal

## 📱 ШАГ 3: Создание записи в App Store Connect

### 3.1. Вход в App Store Connect

1. Откройте [App Store Connect](https://appstoreconnect.apple.com)
2. Войдите с Apple ID, который имеет доступ к Developer Program

### 3.2. Создание нового приложения

1. Нажмите **"Мои приложения"** (My Apps)
2. Нажмите **"+"** → **"Новое приложение"** (New App)
3. Заполните форму:

   **Платформы:**
   - ✅ iOS

   **Название:**
   - `SecureWave` (или ваше название, максимум 30 символов)

   **Основной язык:**
   - Русский (или нужный язык)

   **Bundle ID:**
   - Выберите `com.securewavenew.app` из списка
   - Если его нет в списке, создайте в Developer Portal сначала

   **SKU:**
   - `securewave-app-001` (уникальный идентификатор, только для вас)

   **Пользовательский доступ:**
   - Полный доступ (Full Access) - рекомендуется

4. Нажмите **"Создать"** (Create)

### 3.3. Настройка App Information

1. В разделе **"App Information"** заполните:
   - **Категория:** Социальные сети (Social Networking) или Коммуникации (Communication)
   - **Подкатегория:** (опционально)
   - **Контент для детей:** Нет (если не детское приложение)

2. Сохраните изменения

## 🏗️ ШАГ 4: Сборка релизной версии

### 4.1. Очистка проекта

```bash
cd /Users/vladimir/development/securewave_app

# Очистка Flutter
flutter clean
flutter pub get

# Очистка iOS зависимостей
cd ios
pod deintegrate
pod install
cd ..
```

### 4.2. Сборка через Xcode (РЕКОМЕНДУЕТСЯ)

**Это самый надежный способ для первого раза:**

1. Откройте проект в Xcode:
   ```bash
   open ios/Runner.xcworkspace
   ```
   ⚠️ **Важно:** Открывайте `.xcworkspace`, а не `.xcodeproj`!

2. В Xcode:
   - Выберите **Product** → **Scheme** → **Runner**
   - Выберите **Any iOS Device** (не симулятор!)
   - Выберите **Product** → **Archive**

3. Дождитесь завершения архивации (может занять несколько минут)

4. После архивации откроется окно **Organizer**

5. В окне **Organizer**:
   - Выберите созданный архив
   - Нажмите **"Distribute App"**
   - Выберите **"App Store Connect"**
   - Нажмите **"Next"**
   - Выберите **"Upload"**
   - Нажмите **"Next"**
   - Выберите опции:
     - ✅ **Upload your app's symbols** (для crash reports)
     - ✅ **Manage Version and Build Number** (если нужно)
   - Нажмите **"Next"**
   - Проверьте информацию и нажмите **"Upload"**

6. Дождитесь завершения загрузки (может занять 10-30 минут)

### 4.3. Альтернатива: Сборка через командную строку

```bash
# Сборка IPA файла
flutter build ipa --release

# Готовый файл будет в:
# build/ios/ipa/securewave_app.ipa
```

**Загрузка через Transporter:**

1. Установите [Transporter](https://apps.apple.com/app/transporter/id1450874784) из Mac App Store
2. Откройте Transporter
3. Перетащите IPA файл в окно
4. Нажмите **"Deliver"**
5. Войдите с Apple ID

## ⚠️ Частые проблемы и решения

### Проблема 1: Ошибка подписи кода

**Симптомы:**
- "Code signing error"
- "No signing certificate found"

**Решение:**
1. В Xcode: **Runner** → **Signing & Capabilities**
2. Убедитесь, что выбрана правильная **Team**: `Q5CPN332XB`
3. Убедитесь, что **"Automatically manage signing"** включено
4. Если ошибка сохраняется:
   - **Product** → **Clean Build Folder** (Shift + Cmd + K)
   - Перезапустите Xcode
   - Попробуйте снова

### Проблема 2: Ошибка при загрузке IPA

**Симптомы:**
- "Invalid bundle"
- "Upload failed"

**Решение:**
1. Проверьте размер файла (максимум 4GB)
2. Убедитесь, что используется правильный `ExportOptions.plist`
3. Проверьте интернет-соединение
4. Попробуйте через Transporter вместо Xcode

### Проблема 3: Билд не появляется в App Store Connect

**Симптомы:**
- Билд загружен, но не виден в списке

**Решение:**
1. Подождите 30-60 минут (обработка может занять время)
2. Проверьте, что версия и build number уникальны
3. Убедитесь, что Bundle ID совпадает
4. Проверьте email на наличие ошибок от Apple

### Проблема 4: Отклонение модерации

**Симптомы:**
- Статус "Rejected"
- Email с причиной отклонения

**Решение:**
1. **Внимательно прочитайте причину отклонения**
2. Исправьте указанные проблемы:
   - Обновите описание
   - Исправьте баги
   - Добавьте недостающую информацию
3. Обновите версию в `pubspec.yaml` (увеличьте build number)
4. Соберите и загрузите новую версию
5. Добавьте примечания для рецензента с объяснением исправлений
6. Отправьте повторно

**Частые причины отклонения:**
- Отсутствие политики конфиденциальности
- Неполное описание разрешений
- Баги в приложении
- Нарушение правил App Store

### Проблема 5: Ошибки сборки Flutter

**Симптомы:**
- Ошибки компиляции
- Проблемы с зависимостями

**Решение:**
```bash
# Полная очистка
flutter clean
flutter pub get
cd ios
pod deintegrate
pod install
cd ..
flutter build ipa --release
```
