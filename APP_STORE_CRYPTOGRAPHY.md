# 🔐 Информация о криптографии для App Store Connect

## Вопрос: Алгоритмы шифрования каких типов используются в вашем приложении?

### ✅ Ответ: Стандартные алгоритмы шифрования

Приложение SecureWave использует **только стандартные алгоритмы шифрования**, принятые международными организациями по стандартизации.

---

## 📋 Используемые алгоритмы и стандарты

### 1. **TLS/SSL (Transport Layer Security / Secure Sockets Layer)**
- **Стандарт:** IETF RFC 8446 (TLS 1.3), RFC 5246 (TLS 1.2)
- **Использование:** Шифрование всех данных при передаче между клиентом и сервером
- **Алгоритмы:**
  - AES (Advanced Encryption Standard) - 128/256 бит
  - ChaCha20-Poly1305
  - RSA для обмена ключами
  - ECDHE (Elliptic Curve Diffie-Hellman Ephemeral)
  - SHA-256, SHA-384 для хэширования

### 2. **WebRTC (Web Real-Time Communication)**
- **Стандарт:** IETF RFC 8825, W3C WebRTC
- **Использование:** Шифрование голосовых и видеозвонков
- **Алгоритмы:**
  - **DTLS (Datagram Transport Layer Security)** - IETF RFC 6347
    - AES-GCM для шифрования
    - ECDHE для обмена ключами
  - **SRTP (Secure Real-time Transport Protocol)** - IETF RFC 3711
    - AES для шифрования медиа-потоков
    - HMAC-SHA1 для аутентификации

### 3. **Dart Crypto Package**
- **Пакет:** `crypto: ^3.0.3` (стандартная библиотека Dart)
- **Использование:** Хэширование для кэширования и идентификации файлов
- **Алгоритмы:**
  - MD5 (только для хэширования URL, не для шифрования)
  - SHA-256, SHA-512 (стандарты NIST FIPS 180-4)

### 4. **Операционная система Apple**
- **Использование:** 
  - Keychain Services для безопасного хранения токенов
  - Data Protection API для защиты данных на устройстве
  - Встроенные криптографические функции iOS

---

## ✅ Соответствие стандартам

Все используемые алгоритмы соответствуют стандартам:

- ✅ **IETF (Internet Engineering Task Force)**
  - TLS/SSL (RFC 8446, RFC 5246)
  - DTLS (RFC 6347)
  - SRTP (RFC 3711)

- ✅ **NIST (National Institute of Standards and Technology)**
  - AES (FIPS 197)
  - SHA-256, SHA-512 (FIPS 180-4)

- ✅ **IEEE (Institute of Electrical and Electronics Engineers)**
  - Стандарты сетевой безопасности

- ✅ **W3C (World Wide Web Consortium)**
  - WebRTC стандарты

---

## ❌ Что НЕ используется

- ❌ Частные или проприетарные алгоритмы шифрования
- ❌ Кастомные алгоритмы шифрования
- ❌ Алгоритмы, не принятые международными организациями
- ❌ Собственные реализации криптографических алгоритмов

## 🔍 Детальная информация

### TLS/SSL соединения

Все HTTP/HTTPS запросы используют:
- **Протокол:** TLS 1.2 или выше
- **Шифрование:** AES-128/256-GCM, ChaCha20-Poly1305
- **Обмен ключами:** ECDHE с кривыми P-256, P-384
- **Хэширование:** SHA-256, SHA-384

### WebRTC звонки

Голосовые и видеозвонки защищены:
- **DTLS:** для установления безопасного соединения
- **SRTP:** для шифрования медиа-потоков
- **Алгоритмы:** AES-128/256, HMAC-SHA1
- **Ключи:** генерируются автоматически для каждого звонка

### Хранение данных

- **Keychain Services:** для токенов аутентификации
- **Data Protection API:** для защиты локальных данных
- **Хэширование:** MD5 только для идентификации файлов (не для безопасности)
