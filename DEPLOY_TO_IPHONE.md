# 📱 Установка приложения на iPhone для скриншотов

## 🎯 Цель
Установить свежую версию приложения на iPhone для создания скриншотов для App Store.

---

## ⚡ Быстрая установка

### Шаг 1: Подготовка

```bash
cd /Users/vladimir/development/securewave_app

# Очистка
flutter clean
flutter pub get

# Обновление iOS зависимостей
cd ios
pod install
cd ..
```

### Шаг 2: Подключите iPhone

1. Подключите iPhone к Mac через USB
2. Разблокируйте iPhone
3. На iPhone: **Настройки** → **Основные** → **VPN и управление устройством**
4. Доверьтесь компьютеру (если появится запрос)

### Шаг 3: Проверка устройства

```bash
# Проверить подключенные устройства
flutter devices
```

Должен появиться ваш iPhone, например:
```
iPhone (mobile) • 00008140-001C5C820C09801C • ios • iOS 17.0
```

### Шаг 4: Сборка и установка

**Вариант A: Через Flutter (РЕКОМЕНДУЕТСЯ)**

```bash
# Сборка и установка на подключенный iPhone
flutter run --release

# Или для debug режима (быстрее, но медленнее работает)
flutter run --debug
```

**Вариант B: Через Xcode**

1. Откройте проект:
   ```bash
   open ios/Runner.xcworkspace
   ```

2. В Xcode:
   - Выберите ваш iPhone в списке устройств (вверху рядом с кнопкой Run)
   - Нажмите **▶️ Run** (Cmd + R)
   - Или **Product** → **Run**

3. Дождитесь установки и запуска

## 📸 Создание скриншотов

### Размеры для App Store

#### iPhone 6.7" (iPhone 14 Pro Max, 15 Pro Max):
- **Размер:** 1290 x 2796 пикселей (портрет)
- **Минимум:** 1 скриншот
- **Максимум:** 10 скриншотов

#### iPhone 6.5" (iPhone 11 Pro Max, XS Max):
- **Размер:** 1242 x 2688 пикселей (портрет)
- **Минимум:** 1 скриншот
- **Максимум:** 10 скриншотов

#### iPhone 5.5" (iPhone 8 Plus):
- **Размер:** 1242 x 2208 пикселей (портрет)
- **Минимум:** 1 скриншот
- **Максимум:** 10 скриншотов

### Как сделать скриншоты на iPhone

1. **Откройте нужный экран в приложении**
2. **Сделайте скриншот:**
   - iPhone с Face ID: **Кнопка питания + Кнопка увеличения громкости** (одновременно)
   - iPhone с Touch ID: **Кнопка питания + Home** (одновременно)
3. **Скриншот сохранится в Фото**

### Перенос скриншотов на Mac

**Вариант 1: Через AirDrop (РЕКОМЕНДУЕТСЯ)**
1. На iPhone: откройте **Фото** → выберите скриншоты
2. Нажмите **Поделиться** → **AirDrop**
3. Выберите ваш Mac
4. Скриншоты появятся в папке **Загрузки**

**Вариант 2: Через iCloud**
1. Убедитесь, что iCloud Photos включен
2. Скриншоты автоматически синхронизируются
3. Откройте **Фото** на Mac

**Вариант 3: Через Image Capture**
1. Подключите iPhone к Mac
2. Откройте **Image Capture** (Программы → Утилиты)
3. Выберите скриншоты и импортируйте

### Проверка размеров скриншотов

```bash
# Проверить размер скриншота
file ~/Downloads/IMG_*.png

# Или через sips
sips -g pixelWidth -g pixelHeight ~/Downloads/IMG_*.png
```

### Изменение размера (если нужно)

Если ваш iPhone имеет другой размер экрана, можно изменить размер скриншота:

```bash
# Для iPhone 6.7" (1290 x 2796)
sips -z 2796 1290 исходный_скриншот.png --out screenshot_6.7.png

# Для iPhone 6.5" (1242 x 2688)
sips -z 2688 1242 исходный_скриншот.png --out screenshot_6.5.png

# Для iPhone 5.5" (1242 x 2208)
sips -z 2208 1242 исходный_скриншот.png --out screenshot_5.5.png
```

⚠️ **Важно:** Изменение размера может ухудшить качество. Лучше использовать скриншоты с устройства нужного размера.

## 🎨 Советы для скриншотов

### Что показать:

1. **Главный экран** - список чатов
2. **Экран чата** - переписка с сообщениями
3. **Профиль/Настройки** - основные функции
4. **Звонки** - интерфейс звонков (если есть)
5. **Медиа** - отправка фото/видео
6. **Уведомления** - push-уведомления

### Рекомендации:

- ✅ Используйте реальные данные (не тестовые)
- ✅ Покажите основные функции приложения
- ✅ Убедитесь, что текст читаемый
- ✅ Используйте светлый фон (если возможно)
- ✅ Добавьте текстовые подписи (опционально, в графическом редакторе)
- ✅ Сделайте несколько скриншотов для разных экранов

### Избегайте:

- ❌ Личных данных других пользователей
- ❌ Номеров телефонов и email адресов
- ❌ Конфиденциальной информации
- ❌ Размытых или некачественных изображений

## 🔧 Решение проблем

### Проблема: Устройство не определяется

```bash
# Проверить подключение
flutter devices

# Если не видно:
# 1. Проверьте USB кабель
# 2. Разблокируйте iPhone
# 3. Доверьтесь компьютеру на iPhone
# 4. Перезапустите Xcode
```

### Проблема: Ошибка подписи кода

1. Откройте проект в Xcode:
   ```bash
   open ios/Runner.xcworkspace
   ```

2. **Runner** → **Signing & Capabilities**
3. Убедитесь, что выбрана правильная **Team**
4. Включите **"Automatically manage signing"**

### Проблема: Приложение не устанавливается

1. Проверьте, что на iPhone достаточно места
2. Убедитесь, что iPhone разблокирован
3. Проверьте настройки разработчика на iPhone:
   - **Настройки** → **Основные** → **VPN и управление устройством**
   - Должен быть ваш профиль разработчика

### Проблема: Размер скриншота не соответствует требованиям

Используйте команду `sips` для изменения размера (см. выше) или сделайте скриншот на устройстве нужного размера.
